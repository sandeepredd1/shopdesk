# ShopDesk

A responsive store administration dashboard built with React, TypeScript,
Tailwind CSS, Express, MongoDB Atlas and JWT authentication.

## Features

- Secure login and protected routes
- Dashboard with product, order, revenue and low-stock statistics
- Orders-per-day chart using Recharts
- Product CRUD, search, category filtering and pagination
- Order status management
- Profile editing and password changes
- Responsive sidebar and navigation
- Loading, error and empty states
- Form validation and success/error notifications

## Tech Stack

Frontend: React, Vite, TypeScript, Tailwind CSS, React Router, Axios, Recharts
Backend: Node.js, Express, Mongoose, MongoDB Atlas, JWT, bcrypt
